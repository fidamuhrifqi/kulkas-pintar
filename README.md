# Kulkas Pintar Bot 🤖🧊

Kulkas Pintar adalah sebuah asisten virtual berbasis Telegram Bot yang dirancang khusus untuk membantu keluarga dalam mencatat, melacak, dan mengelola stok makanan (inventaris) di dalam kulkas rumah. Bot ini menggunakan kecerdasan buatan (AI) untuk memahami input natural berbahasa Indonesia, sehingga pengguna cukup mengetik pesan seperti *"masuk telur setengah kilo"* atau *"keluar 2 buah tomat"* tanpa perlu mengingat format yang kaku.

> **Catatan:** Aplikasi ini adalah hasil dari metodologi **vibecode** dan dievaluasi secara berkala oleh *developer*-nya untuk memastikan akurasi AI, keandalan sistem, dan kenyamanan pengguna (UX).

## Fitur Utama
- **📦 Stok Kulkas:** Melacak inventaris kulkas secara terstruktur dan rapi.
- **📥 Masuk & 📤 Keluar Barang:** Input via *natural language*, AI akan mem-parsing otomatis, melakukan perhitungan matematis, dan mengkonversi satuan bahan makanan.
- **🍳 Rekomendasi Resep Pintar:** Memberikan ide masakan (meal ideas) spesifik berdasarkan bahan apa saja yang **saat ini sedang ada di kulkas**.
- **📖 Manajemen Resep:** Simpan resep favorit dan edit instruksi masaknya kapan saja.
